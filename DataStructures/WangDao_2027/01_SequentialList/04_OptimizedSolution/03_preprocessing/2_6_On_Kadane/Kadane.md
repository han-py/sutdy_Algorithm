# Kadane 算法（卡登算法）：最大连续子数组和

## 1. 问题描述
给定一个整数数组 `A`，要求找出一个**连续子数组**，使它们的和最大，并返回这个最大值。

例如：

```text
A = [1, -2, 3, 5, -3, 4]
```

其中最大连续子数组是：

```text
[3, 5]
```

它的和是 `8`，所以答案是 `8`。

---

## 2. Kadane 算法的核心思想
Kadane 算法是一种非常经典的线性动态规划方法，它的核心想法可以概括为一句话：

> **对每个位置 `i`，只考虑“以 `A[i]` 结尾的最大连续子数组和”。**

这样一来，我们不需要枚举所有子数组，只需要在遍历数组的过程中维护两个量：

- `cur_max`：**当前以 `A[i]` 结尾的最大连续子数组和**
- `global_max`：**遍历到目前为止的最大连续子数组和**

---

## 3. 状态转移方程
设 `dp[i]` 表示：

> 以 `A[i]` 结尾的最大连续子数组和。

那么有：

```text
dp[i] = max(A[i], dp[i-1] + A[i])
```

### 为什么是这个转移？
对于位置 `i`，只有两种选择：

1. **自己重新开始**
   - 如果前面的和是负数，那么把它加上只会拖累结果。
   - 所以直接从 `A[i]` 重新开始。

2. **接在前一个子数组后面**
   - 如果 `dp[i-1]` 是正数，那么把 `A[i]` 接上可以让和更大。

因此只需比较这两种情况，取较大者即可。

---

## 4. 为什么这个贪心/动态规划是正确的？
### 4.1 局部最优的含义
当我们计算 `dp[i]` 时，只关心“**以 `i` 结尾**”的最优解，而不关心更早之前的完整路径。

这是因为：
- 连续子数组必须连续；
- 若前缀和已经是负数，那么它对后续结果只会产生负贡献；
- 所以前面如果拖后腿，就果断舍弃，从当前位置重新开始。

### 4.2 全局最优的获取
虽然 `dp[i]` 只表示“以 `i` 结尾”的最优值，但真正答案可能出现在任何位置。

因此需要再维护：

```text
global_max = max(global_max, dp[i])
```

遍历整个数组后，`global_max` 就是最终答案。

---

## 5. 示例演算
以数组：

```text
[1, -2, 3, 5, -3, 4]
```

为例，逐步分析。

### 初始状态
```text
cur_max = A[0] = 1
global_max = A[0] = 1
```

### 处理 `A[1] = -2`
```text
cur_max = max(-2, 1 + (-2)) = max(-2, -1) = -1
global_max = max(1, -1) = 1
```

### 处理 `A[2] = 3`
```text
cur_max = max(3, -1 + 3) = max(3, 2) = 3
global_max = max(1, 3) = 3
```

### 处理 `A[3] = 5`
```text
cur_max = max(5, 3 + 5) = 8
global_max = max(3, 8) = 8
```

### 处理 `A[4] = -3`
```text
cur_max = max(-3, 8 + (-3)) = 5
global_max = max(8, 5) = 8
```

### 处理 `A[5] = 4`
```text
cur_max = max(4, 5 + 4) = 9
global_max = max(8, 9) = 9
```

如果数组长度取完整的 6 个元素，那么最终答案是 `9`。

> 注意：你当前的 `Kadane.cpp` 里写的是 `int n = 4;`，因此实际只计算前 4 个元素 `[1, -2, 3, 5]`，答案是 `8`。

## 6. 代码解释

```cpp
int maxSubArray(int A[], int n) {
    int cur_max = A[0];
    int global_max = A[0];
    for (int i = 1; i < n; ++i) {
        cur_max = max(A[i], cur_max + A[i]);
        global_max = max(global_max, cur_max);
    }
    return global_max;
}
```

### 变量含义
- `cur_max`
  - 表示“以当前元素结尾”的最大连续子数组和。
- `global_max`
  - 表示遍历到当前为止的最大值。

### 每一步做了什么
```cpp
cur_max = max(A[i], cur_max + A[i]);
```
表示：
- 要么从 `A[i]` 重新开始；
- 要么把 `A[i]` 接到前面的最优子数组后面。

```cpp
global_max = max(global_max, cur_max);
```
表示：
- 如果当前的 `cur_max` 更大，就更新全局答案。

---

## 7. 复杂度分析
- **时间复杂度**：`O(n)`
  - 只遍历数组一次。
- **空间复杂度**：`O(1)`
  - 只使用了两个辅助变量。

这也是 Kadane 算法非常经典的原因：**高效、简洁、易实现**。

---

## 8. 边界情况
### 8.1 全是负数
例如：

```text
[-5, -2, -8]
```

此时答案不是 `0`，而是最大的那个负数：`-2`。

原因：题目要求的是**非空连续子数组**，不能选空数组。

### 8.2 只有一个元素
例如：

```text
[7]
```

答案就是 `7`。

### 8.3 全是正数
例如：

```text
[1, 2, 3]
```

答案就是整个数组的和：`6`。

---

## 9. 常见错误
### 错误 1：把答案初始化为 0
如果数组全是负数，这样会错误地输出 `0`。

正确做法是：
- 初始化为第一个元素 `A[0]`。

### 错误 2：只维护当前和，不维护全局最大值
这样会漏掉“最佳子数组并不一定以最后一个元素结尾”的情况。

### 错误 3：把“子数组”和“子序列”混淆
Kadane 算法解决的是**连续子数组**，不是任意子序列。

## 10. 一个更完整的写法
如果想让代码更健壮一点，可以这样写：

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int maxSubArray(const int A[], int n) {
    if (n <= 0) return 0;
    int cur_max = A[0];
    int global_max = A[0];
    for (int i = 1; i < n; ++i) {
        cur_max = max(A[i], cur_max + A[i]);
        global_max = max(global_max, cur_max);
    }
    return global_max;
}

int main() {
#ifdef ACM_LOCAL
    freopen("data.in", "r", stdin);
    freopen("data.out", "w", stdout);
#endif
    const int A[] = {1, -2, 3, 5, -3, 4};
    const int n = sizeof(A) / sizeof(A[0]);
    cout << maxSubArray(A, n) << endl; // 输出：9
    return 0;
}
```

---

## 11. 总结
Kadane 算法的本质是：

1. 用 `dp[i]` 表示“以 `A[i]` 结尾的最大连续子数组和”；
2. 通过 `dp[i] = max(A[i], dp[i-1] + A[i])` 做状态转移；
3. 用 `global_max` 记录遍历过程中的最大值；
4. 最终在线性时间内求出最大连续子数组和。

它是动态规划中非常经典、非常值得掌握的一道基础题。

---

## 12. 一句话记忆
> **如果前面的和会拖后腿，就从当前元素重新开始。**

这就是 Kadane 算法最核心的思想。
