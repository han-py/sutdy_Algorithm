# 折半查找（二分查找）
## 核心要素
- **使用条件**：有序的顺序表（数组）。
- **核心思想**：通过不断与区间中点比较，每次都将查找范围缩小一半。
- **复杂度**：时间 $O(logn)$，空间 $O(1)$。

> 当题目出现**有序数组**（且是顺序表，不是链表）时，优先考虑折半查找。

## 两种经典模板

|对比项|模板一：『等值判断』模板（优先使用）|模板二：『区间收敛』模板|
| ---- | ---- | ---- |
|适用场景|查找一个确切的值，通常适合元素不重复。|查找满足条件的第一个或最后一个元素，元素可以重复。|
|查找成功|`A[mid] == x` 判断。|区间缩小为只有一个元素，需额外判断。|
|查找失败|区间中没有元素|区间缩小为只有一个元素，需额外判断。|
|循环条件|`while (L <= R)`（区间没有元素时退出循环）|`while (L < R)`（区间收敛为一个元素时退出循环）|
|边界更新逻辑|`R = mid - 1` 或 `L = mid + 1`（直接排除 mid）|`R = mid` 或 `L = mid + 1`（可能不能排除 mid）|

### 模板一：『等值判断』模板
> 这是最基础、最常用的模板，其核心是在循环内部通过 `if (A[mid] == x)` 直接判断是否找到了目标值。

```c
// 折半查找
int B_Search(int A[], int L, int R, int x)
{
    int mid;
    while (L <= R)
    {
        mid = (L + R) / 2;
        if(A[mid] == x)
            return mid;         //查找成功，返回下标
        else if(A[mid] > x)
            R = mid - 1;        // x 在左半区间，L ~ mid-1
        else
            L = mid + 1;        // x 在右半区间，mid+1 ~ R
    }
    return -1;                  // 查找失败
}
```

### 模板二：『区间收敛』模板
> 这个模板的核心思想是通过不断缩小区间，最终将区间收敛为一个元素，然后判断是否找到了目标值。
```c
// 折半查找：区间收敛模板，查找第一个等于 x 元素的下标
int B_Search(int A[], int L, int R, int x)
{
    int mid;
    while (L < R)
    {
        mid = (L + R) / 2;
        if (A[mid] >= x)
            R = mid;
        else
            L = mid + 1;
    }
    return L;
}
```
