# 图的广度优先搜索(BFS) 学习示例

本目录包含一个用于学习图的广度优先搜索（BFS）的 C++ 程序：

- `bfs_learning.cpp`

程序内容包括：
- 邻接矩阵表示法的 BFS
- 邻接表表示法的 BFS
- 中文注释
- 详细的运行输出：访问顺序、父节点、距离、入队与出队过程

## 编译与运行（Windows / PowerShell）

```powershell
chcp 65001

g++ -std=c++17 -O2 -Wall .\bfs_learning.cpp -o .\bfs_learning.exe
.\bfs_learning.exe
```

## 程序学习重点

1. BFS 使用队列（queue）来实现“按层扩展”。
2. 邻接矩阵和邻接表都可以实现 BFS，只要能枚举邻接点即可。
3. BFS 常用于：无权图最短路、层次遍历、连通块统计等。
4. 通过 `dist[]` 和 `parent[]` 可以分析最短距离和路径重建。

## 示例图说明

图中有 7 个节点，边集合为：

- 0-1
- 0-2
- 1-3
- 1-4
- 2-5
- 3-4
- 5-6

从节点 0 开始，BFS 会按层次访问：

- 第 0 层：0
- 第 1 层：1, 2
- 第 2 层：3, 4, 5
- 第 3 层：6
