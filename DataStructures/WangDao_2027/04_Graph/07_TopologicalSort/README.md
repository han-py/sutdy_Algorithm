# 拓扑排序（Topological Sort）学习示例

本目录包含一个自包含的 C++ 示例程序 `topological_sort_learning.cpp`，用于学习有向无环图（DAG）的拓扑排序。

程序提供以下内容：

- 邻接矩阵版 Kahn 算法（入度法）
- 邻接表版 Kahn 算法（入度法）
- 邻接表版 DFS 拓扑排序（拓展理解）

所有注释与输出均为中文，程序会构造示例 DAG 并打印每一步执行过程，方便学习拓扑排序的思路。

## 1. 拓扑排序是什么

拓扑排序是对**有向无环图（DAG）**中的顶点进行排序，使得对每一条边 `u -> v`，在排序中 `u` 都排在 `v` 前面。

### 重要结论
- 只有 DAG 才能进行拓扑排序
- 如果图中存在环，就不存在合法的拓扑序

## 2. 本程序使用的算法

### 2.1 Kahn 算法（入度法）

思路：
1. 统计每个顶点的入度
2. 把所有入度为 0 的顶点放入队列
3. 反复取出队头顶点，加入结果序列
4. 删除它的所有出边，更新相邻顶点入度
5. 如果最终输出的顶点数少于总顶点数，说明图中有环

特点：
- 思路直观
- 非常适合教学和工程实现
- 对邻接表和邻接矩阵都适用

### 2.2 DFS 拓扑排序

思路：
1. 对图做深度优先搜索
2. 当一个顶点的所有后继都访问完后，再把它加入序列
3. 最后将结果逆序输出，就得到拓扑序

特点：
- 更适合从 DFS 的角度理解拓扑排序
- 也能检测环：若在 DFS 中遇到“访问中”的顶点，就说明存在环

## 3. 本程序内容

`topological_sort_learning.cpp` 中包含：

- `GraphMatrix`：邻接矩阵表示
  - `topoSortKahn()`
- `GraphList`：邻接表表示
  - `topoSortKahn()`
  - `topoSortDFS()`

主函数中会构造一个示例 DAG，并依次演示上述算法。

## 4. 示例图

程序中的示例 DAG 顶点为 `0..5`，边如下：

- `0 -> 1`
- `0 -> 2`
- `1 -> 3`
- `2 -> 3`
- `2 -> 4`
- `3 -> 5`
- `4 -> 5`

一个合法的拓扑序例如：

- `0 -> 1 -> 2 -> 3 -> 4 -> 5`
- `0 -> 2 -> 1 -> 4 -> 3 -> 5`

只要满足所有边的先后关系，拓扑序就都是正确的。

## 6. 输出你会看到什么

程序会输出：

- 邻接矩阵 / 邻接表的图结构
- 初始入度数组
- 每次出队的顶点
- 每条边删除后入度变化
- 最终拓扑序
- DFS 版中“访问”“回溯”“发现环”的过程

## 7. 学习建议

建议按下面顺序学习：

1. 先看 Kahn 算法，理解“入度为 0 的点先处理”
2. 再看 DFS 版，理解“后序回溯 + 逆序输出”
3. 最后对比邻接矩阵和邻接表：
   - 邻接矩阵更适合展示图结构
   - 邻接表更适合稀疏图和实际编程
