# DataStructuresStudyPack

这是一个全新的英文目录数据结构学习资料包，内容全部采用中文讲解，代码文件保留 `main.cpp` 风格的可运行入口，适合按章节逐步学习、练习和复习。

## 先看这里

- [总目录索引](./Master_Index.md)

## 目录说明

- `00_Foundation`：预备知识、复杂度分析、学习方法。
- `01_Linear_Structures`：数组、链表、栈、队列、双端队列、字符串。
- `02_Tree_Structures`：二叉树、BST、平衡树、堆、Trie、并查集。
- `03_Graph_Structures`：图的表示、遍历、拓扑排序、最短路、最小生成树、进阶图论。
- `04_Hash_And_Map`：哈希表、哈希集合、哈希映射、布隆过滤器。
- `05_Advanced_Data_StructURES`：树状数组、线段树、跳表、B 树 / B+ 树、后缀结构。
- `06_Algorithm_DataStructure_Linkage`：算法与数据结构联动示例。
- `07_Review_Checklists`：复习清单、易错点、总模板。

## 使用方式

1. 先看对应章节的 `README.md`。
2. 再看同目录下的 `Chapter_Index.md`，快速把握学习顺序、重点和易错点。
3. 再看同目录下的 `Template_Index.md`，快速找到本章可复用模板。
4. 再看同目录下的结构级 `.md` 讲义，例如 `Array.md`、`BinaryTree.md`、`ShortestPath.md`。
5. 再看同目录下的 `.cpp` 示例文件，它们都可以单独编译运行。
6. 使用 CMake 或单文件编译都可以。
7. 先读讲义，再看代码，再自己手写一遍，最后做题验证。
